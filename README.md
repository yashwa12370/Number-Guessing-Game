🎯 Number Guessing Game

A fun, interactive, and responsive Number Guessing Game built with HTML, CSS, and JavaScript.
The player has to guess a randomly generated number within a limited number of attempts. The game provides hints, tracks the player's performance, and displays the guess history.

Features

- 🎯 Random number generation
- 🎚️ Multiple difficulty levels
- 💡 Helpful hints
- 🔢 Attempts tracking
- 🏆 Score system
- 🔥 Streak tracking
- 📜 Guess history
- 🥇 Best score tracking
- 🎉 Winning result screen
- 🔄 New game / reset option
- 📱 Responsive design
- 🌙 Modern dark-themed interface

Technologies Used

- HTML5 — Structure
- CSS3 — Styling and responsive UI
- JavaScript — Game logic and interactivity

How to Play

1. Select a difficulty level.
2. A random number is generated.
3. Enter your guess in the input field.
4. Click Check Guess.
5. Use the hints to improve your next guess.
6. Try to find the correct number before your attempts run out.
7. Your score and streak are updated based on your performance.

Game Tracking

The game keeps track of:

- Current score
- Number of attempts
- Current streak
- Best score
- Previous guesses
